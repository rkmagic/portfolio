## Context

Personal side project, started March 2026. I had long recordings from meetings, interviews, and voice notes, and needed a quick way to turn a 1-hour recording into notes without another SaaS subscription.

Repo: [rkmagic/stt_simple_asap](https://github.com/rkmagic/stt_simple_asap).

## Problem

I record many meetings, conversations, and interviews on my phone microphone for self-reference and reflection. Recordings ran from about 20 minutes to over an hour. LLM chat tools rejected the files as too large. Consumer transcription sites did the same, or priced themselves like a product I would not pay for occasional personal use. OpenAI Whisper was cheap enough to run myself, but the API caps uploads at about 25 MB, which most of my recordings exceeded.

The real job was not "call an API." It was: drop in several messy audio files, wait without guessing if it hung, and walk away with transcripts I could copy, download, or zip.

## Process

I scoped it as a local Node app first: upload UI, Whisper on the server, and text to review in the browser. FFmpeg was the non-negotiable dependency for anything over the size limit: `ffprobe` for duration, `ffmpeg` to split with stream copy so I was not re-encoding hour-long files. It took some iteration to get FFmpeg working correctly on the server. When I make enough money, I'm going to donate to FFmpeg for sure.

Once that worked, I automated dropping recordings from my phone into the Node app.

I created an API for the Node app that accepts recordings, hosted on Render with an optional bearer `API_KEY` so I could put it on a public URL without anyone burning my OpenAI key. Then I built a simple n8n workflow that pulls files from Google Drive and writes transcribed notes back to Google Drive. It runs on my laptop via Docker.

I first tried Make, but hit issues. Multipart field names were inconsistent (`files` vs `file` vs `audio` vs `audio_file`), extra file parts overloaded handling, and Telegram ".m4a" voice notes were actually 3GPP (`ftyp 3gp4`) that Whisper rejects. Those are now remuxed to AAC in MP4 before the API call.

Finally, I use a Claude skill to turn transcripts into a `.md` summary.

![n8n-workflow](/images/n8n_meeting.png)

The n8n workflow is simple. A timer wakes the Render server when it has gone to sleep from inactivity.

**Final Stack:** Node.js, Express, n8n, OpenAI Whisper API, FFmpeg/ffprobe, Docker, Render

## Outcome

I can now transcribe long recordings for a few cents ($0.006/minute) without paying monthly SaaS subscriptions.

It also feeds product discovery: I turn conversations into notes classified into insights, action items, key points, and open questions.
